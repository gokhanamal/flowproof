# Security Policy

## Supported versions

FlowProof is currently pre-1.0. Security fixes are provided only for the latest
published `0.x` release. Older releases and unreleased branches are unsupported.

| Version | Supported |
| --- | --- |
| Latest `0.x` release | Yes |
| Older releases | No |

## Reporting a vulnerability

Do not report suspected vulnerabilities in a public issue, pull request, or
discussion. Use [GitHub private vulnerability
reporting](https://github.com/gokhanamal/flowproof/security/advisories/new) so the
maintainer can investigate without exposing users.

Include the affected version, impact, reproduction steps or a proof of concept,
and any suggested mitigation. Avoid including real credentials, customer data,
or other unnecessary sensitive information.

The maintainer will make a best effort to acknowledge a report within seven days,
coordinate investigation and remediation with the reporter, and publish an
advisory when a fix or mitigation is ready. Response and fix times depend on
severity and maintainer availability; no service-level agreement is offered.

If private vulnerability reporting is temporarily unavailable, use the private
contact information published at
[github.com/gokhanamal](https://github.com/gokhanamal).
