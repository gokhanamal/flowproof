# Support

FlowProof is maintained on a best-effort basis and does not provide a support
service or response-time guarantee.

- For reproducible defects, search existing issues and then use the bug report
  form. Include sanitized logs and a minimal flow when possible.
- For feature proposals or documentation gaps, use the feature request form.
- For setup questions, first review the README, examples, and existing issues. If
  the documentation is incomplete, open a focused feature request describing the
  missing guidance.
- For vulnerabilities, follow [SECURITY.md](SECURITY.md) and never open a public
  issue.
- For conduct concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Please do not share API keys, production credentials, private application data,
screenshots, accessibility dumps, recordings, or unredacted logs. A maintainer
may close requests that cannot be reproduced, fall outside the documented scope,
or require access to sensitive data.
